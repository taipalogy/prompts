# Compositional UI Engine (CUI)

> A Universal String-Chassis Protocol for Multi-Framework Interoperability & Compositional Fluidity

The **Compositional UI Engine (CUI)** evolves the accretion architecture into a dynamic composition framework. It ingests raw prose or text and maps it into structural layouts driven by semantic component containment and flex-based composition fluidly, featuring real-time string highlighting, reactive streaming, strict kinetic docking physics, swappable layout templates, optional autonomous bundling, and pure shorthand manual synthesis modes.

## 2. Composition Shorthand: Syntax Map

| Sigil | Operation | Functional Role |
| --- | --- | --- |
| `+` | **Accretion** | Connects Verbs and Nouns to the chain. |
| `:` | **Targeting** | Identifies the specific Noun or Verb to act upon. |
| `@` | **Styling & Overrides** | Applies a Property, Material, Swappable Template, or Strict Override Flag. |
| `>>` | **Ingest** | Feeds raw text or prose into the synthesis engine. |
| `::` | **Mapping & Fallback** | Assigns ingested content blocks or resolves layout fallbacks (if active). |
| `??` | **Query/Highlight** | Binds input fields to real-time string-matching filters. |
| `()` | **Grouping** | Defines logic blocks and parallel branches. |
| `->` | **Materialization** | Compiles the polymer into a single `.html` file. |

## 3. Compositional Hierarchy Registry (Dynamic Layout Paradigm)

Static pre-defined layout slots are replaced by a **Compositional Hierarchy Engine**. Layout structures are derived dynamically from semantic element containment, indent-driven node stacks, and container-aware box primitives.

* `composition:box` (Flexible Structural Container with Header Bar)
* `composition:textbox` (Form Input Group with Label & Input Field)
* `composition:list` (Grouped List Container)
* `composition:radio` (Selectable Option Item)
* `composition:passage` (Prose Block or Editable Text/Code Area)
* `composition:button` (Interactive Action Control)
* `composition:widget` (Parametric Control Widget)
* `composition:archetype` (Complex Integrated Application Archetypes with Swappable Layouts & Strict Override Toggles)

## 5. Execution Rules (The Physics)

* **Item 1: The Ephemeral Protocol**: The final output compiles down to a single self-contained HTML file requiring no external server dependencies.
* **Item 2: Kinetic Docking (0/64)**: Structural spacing adheres strictly to binary boundaries (fused **0px** or structured **64px** gutters).
* **Item 3: Reactive Highlighting**: Input queries (`??`) perform client-side DOM node traversal, dynamically wrapping target substrings in highlighted spans without altering underlying layout flow.
* **Item 4: Optional Autonomous Auto-Bundling**: When controller scripts or behavior bindings are absent, the engine defaults to auto-injecting runtime logic unless explicitly disabled via the `override:disable_auto_bundle` flag for pure manual synthesis.
* **Item 5: Optional Fallback Template Resolution**: Shorthand chains automatically apply layout templates from `default_template.md` unless explicitly overridden and bypassed via the `override:disable_fallback` flag.
